## Feature 1: YouTube Event Date Extraction

### Test Cases
- [ ] **TC1.1**: Find a YouTube video with "Streamed live on Feb 4, 2026" in description
  - Expected: Event date extracted as "2026-02-04" with type "livestream"
  - Check backend logs for: "Extracted livestream date from description: ..."

- [ ] **TC1.2**: Find a YouTube video with "Premiered Jan 15, 2026" in description
  - Expected: Event date extracted as "2026-01-15" with type "premiere"
  - Verify confidence score is 0.95

- [ ] **TC1.3**: Video with no event date in description
  - Expected: Falls back to upload date or title-based extraction
  - No errors in logs

- [ ] **TC1.4**: Video segment with timestamp
  - Expected: Can deep-link to specific moment (e.g., `&t=330s` for 5:30)
  - Segment title shows timestamp reference

### How to Test
```bash
# Query Neo4j for videos with event metadata
docker-compose exec -T neo4j cypher-shell -u neo4j -p password << EOF
MATCH (r:Resource)
WHERE r.url CONTAINS 'youtube' AND r.title CONTAINS 'Cisco'
RETURN r.title, r.publish_date, r.metadata
LIMIT 5;
EOF
```

## Feature 3: Pipeline Selector (Beta)

### Test Cases
- [ ] **TC3.1**: Default state is "Engine: System (A/B)"
  - Expected: Uses A/B test hash-based assignment
  - No override in network request payload
  - Backend logs: "Using fast/baseline pipeline (A/B test)"

- [ ] **TC3.2**: Switch to "Engine: Fast"
  - Expected: Fast pipeline used immediately
  - Network request includes `"pipeline_override": "fast"`
  - Backend logs: "Pipeline override: ... override=fast -> fast"
  - Responses are instant with template-based answers

- [ ] **TC3.3**: Switch to "Engine: Baseline"
  - Expected: Baseline pipeline used
  - Network request includes `"pipeline_override": "baseline"`
  - Backend logs: "Pipeline override: ... override=baseline -> baseline"
  - Responses use comprehensive LLM synthesis (slower, more detailed)

- [ ] **TC3.4**: Persistence across page refresh
  - Set to "Engine: Fast", refresh page
  - Expected: Dropdown still shows "Fast" selection
  - localStorage contains `pipelineMode: "fast"`

- [ ] **TC3.5**: Compare Fast vs Baseline for same query
  - Query: "What are the latest Wi-Fi 7 features?"
  - Fast: Should return quick template answer (~500ms)
  - Baseline: Should return detailed synthesis (~2000ms)
  - Both should answer correctly but with different depth

### Visual Checks
- [ ] Pipeline dropdown has green border accent
- [ ] Tooltip shows on hover: "Fast uses instant templates..."
- [ ] Dropdown disabled during loading
- [ ] Selection persists in localStorage

### Telemetry Checks

## Analytics to Monitor (Post-Deployment)

### Metrics to Track
1. **Pipeline Override Usage**
   - % of queries using System vs Fast vs Baseline
   - User switching patterns (System→Fast→Baseline)

2. **Citation Filtering Impact**
   - Avg documents shown in References section
   - % of queries with Additional Context expanded

3. **YouTube Event Dating**
   - % of videos with extracted event dates
   - Accuracy of date extraction (manual spot checks)

### Queries for Analytics
```sql
-- Pipeline override distribution (PostgreSQL)
SELECT 
  pipeline_override,
  COUNT(*) as query_count,
  AVG(processing_time_ms) as avg_latency
FROM oracle_query_history
WHERE created_at > NOW() - INTERVAL '7 days'
GROUP BY pipeline_override;

-- Citation filtering stats
SELECT
  AVG(JSONB_ARRAY_LENGTH(response->'citations')) as avg_citations,
  AVG(JSONB_ARRAY_LENGTH(response->'documents')) as avg_total_docs
FROM oracle_query_history
WHERE mode = 'answer';
```
