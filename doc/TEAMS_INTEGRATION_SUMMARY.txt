🎓 HOW IT WORKS (90 seconds)

  Layer 1: Teams Hosts the Iframe
    • teams.microsoft.com hosts iframe
    • Points to: https://d23ew7gbss3vnh.cloudfront.net/teams (production)
    • Or: http://localhost:3000/teams (local dev)

  Layer 2: User Authentication
    • User already logged in via Cognito
    • httpOnly cookies sent automatically
    • Auth service validates on every request

  Layer 3: Chat Interface
    • User types message in Chat section
    • POST /api/chat/query sends to backend
    • Backend responds with AI answer
    • Message appears in chat

  Layer 4: Real-Time Feed Updates
    • SSE stream: GET /api/feed/stream
    • Backend sends events as they occur
    • EventBus processes feed_update events
    • Auto-converts to chat messages
    • Toast notification appears
    • Unread badge increments

  Layer 5: Data Persistence
    • Chat history in PostgreSQL
    • Feed posts in PostgreSQL
    • Knowledge graph in Neo4j
    • No changes to backend architecture
